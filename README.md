# CEUE203 - Object Oriented Programming (D26IT129 - Keval Solanki)

| Folder | Contents |
| --- | --- |
| `Practical-1` ... `Practical-14` | Part A programs. Each practical is one IntelliJ project with one module per program. |
| `MiniBank` | The finished MiniBank console banking application (state after Practical 14). |
| `MiniBank-by-practical/practical-01` ... `14` | MiniBank as it stood at the end of each practical (each folder is its own IntelliJ project). |

Open any practical with IntelliJ IDEA: File > Open, then pick the folder. If IntelliJ reports that the Project SDK is not defined, choose Setup SDK and pick JDK 17 or newer.
Practical-14 and `MiniBank` contain JUnit 5 tests: open the test file, press Alt+Enter on `@Test`, choose "Add JUnit5.x to classpath", then run the test class.
